Modelling Ectoparasite Loads in Southern African Rodents

Project Overview
This repository contains the MATLAB code developed for a Biomathematics 374 research project at Stellenbosch University, supervised by Prof. Sonja Matthee.
The study investigates how environmental conditions and host-specific characteristics influence ectoparasite loads in four southern African rodent species. 
Particular emphasis is placed on comparing the relative contributions of habitat and rodent species.

Statistical Methods
The analyses include:
Descriptive statistics and exploratory data analysis.
Poisson regression.
Negative binomial regression.
Zero-inflated negative binomial regression.
Hurdle negative binomial modelling.
Variable importance analysis and bootstrap comparisons.
Cross-validation and locality sensitivity analysis.
Habitat-dependent simulations and parasite aggregation analyses.
